# Lantern Courier

섬 사이를 오가며 등불을 배달하는 작은 Unity 게임. [BugLoop](https://github.com/aquhm/bugloop) 평가용 데모로 만든다.

이 저장소에는 일부러 넣은 버그가 있다. 버그를 넣은 커밋, 이슈, 수정 커밋이 이력에 남고, BugLoop의 분류·사례 조회·PR 리뷰를 이 이력으로 측정한다. 어떤 버그인지는 여기에 적지 않는다.

## 환경

- Unity 6000.3.5f2, URP
- UniTask 2.5.11 (git UPM)
- R3 1.3.1: 본체는 NuGetForUnity로 `Assets/Packages/`, Unity 연동은 git UPM `com.cysharp.r3`

## 상태

빈 URP 프로젝트. 게임 코드 없음.
